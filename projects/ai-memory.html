不要吃灰｜AI 个人内容记忆助手

一个帮助个人高效留存内容、自动总结并沉淀知识的 AI 助手。

项目背景

在日常聊天、阅读和信息浏览中，很多有价值的内容会快速被淹没。我希望做一个更轻量的记录方式：用户只需要把内容发送给机器人，系统就能自动理解、总结并沉淀下来，而不是让信息继续“吃灰”。

解决方案

我设计了一个基于飞书群聊和自动化工作流的 AI 助手。整体流程是：

  • 用户在飞书群聊中 @机器人并发送内容
  • 系统通过 Webhook 接收消息
  • 调用大模型生成结构化总结
  • 将结果自动写入飞书多维表格
  • 完成内容留存与知识沉淀

核心功能

内容一键记录 AI 自动总结 结构化信息沉淀 飞书多维表格自动写入 适合个人知识管理场景

技术实现

FastAPI LangGraph Feishu Webhook Feishu API LLM

项目收获

这个项目让我真正把“创意 → 工作流 → 产品原型”跑通了一次。我在过程中练习了：

  • 如何把一个模糊想法拆成可执行流程
  • 如何设计 AI Agent 的输入处理输出
  • 如何将自动化系统接入真实工具场景
  • 如何把功能做成可验证的 MVP
